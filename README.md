## Featured Projects

### LendingClub Interest Rate Prediction

**Machine Learning \| Python \| CatBoost \| SHAP \| Cross-Validation**

Built a leakage-safe machine learning approach to predict loan interest
rates using information available at origination. The project used
100,000 training loans and 10,000 test loans and compared multiple model
families.

-   Engineered application-time features including FICO midpoint,
    utilization measures, and transformed financial variables.
-   Compared decision trees, random forests, neural networks, LightGBM,
    XGBoost, and CatBoost.
-   CatBoost was the strongest standalone model, with an out-of-fold
    RMSE of 3.845.
-   Used SHAP and feature importance to explain predictions; FICO,
    utilization, and debt burden emerged as major pricing drivers.
-   Focused on preventing data leakage so the model reflected a
    realistic lending decision.

### Goodreads Personalized Book Recommender

**Recommendation Systems \| Collaborative Filtering \| Gemini \|
Streamlit**

Developed a personalized book recommendation system using Goodreads
ratings from 1,192 active users, 9,964 books, and approximately 164,000
ratings.

-   Compared a bias-based baseline, user-based collaborative filtering,
    and item-based collaborative filtering.
-   Selected UBCF with Pearson similarity because it produced the
    strongest ranked recommendation quality.
-   Added Gemini re-ranking to adapt recommendations to a user's stated
    mood or preferences.
-   Built a Streamlit interface to compare recommendations before and
    after LLM re-ranking.
-   Designed a popularity fallback for users with limited rating
    history.

[View project summary](projects/goodreads-recommender/README.md)

### Hotel Review Text Analytics

**NLP \| Topic Modeling \| LDA \| BERTopic \| Customer Experience**

Analyzed hotel customer reviews to identify recurring experience themes
and translate unstructured feedback into operational recommendations.

-   Used LDA and BERTopic to identify recurring topics in guest reviews.
-   Surfaced themes around cleanliness and staff, location and
    amenities, front-desk/service recovery, room comfort, and lobby
    atmosphere.
-   Connected topic patterns to business recommendations focused on
    service execution and customer feedback loops.
