# Upload to GitHub

Upload the **contents of this folder** to your public
`analytics-portfolio` repository.

The repository root should contain: - `README.md` - `assets/` -
`projects/` - `.gitignore`

Do not upload the ZIP itself.

## Important

The A+E capstone is intentionally excluded because it is covered by an
NDA.

The current portfolio contains actual source code for the Goodreads
Streamlit app and actual executed notebook/code from the hotel-review
analysis. The LendingClub section contains verified results and visuals
but does not pretend to include an original notebook that was not
available.
